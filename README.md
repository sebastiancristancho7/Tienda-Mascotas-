# 🐾 Tienda de Mascotas

Página web pequeña con HTML5, CSS y JavaScript.

## Características
- 3 páginas enlazadas (index, productos, contacto)
- 3 imágenes (perro, gato, conejo)
- 3 botones con funciones JS
- Base de datos MySQL con 2 tablas: `categorias` y `productos`

## Cómo ejecutar
1. Abrir `index.html` en el navegador.
2. Importar `db/tienda_mascotas.sql` en MySQL o phpMyAdmin.
